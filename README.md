# C++ Structures Practice

This repository contains two beginner-friendly C++ programs
that demonstrate the use of structures.

## Exercise 1: Area of Shapes

File: shape_areas.cpp

This program uses a structure to store shape dimensions
and calculate the following:

- Rectangle area
- Circle area
- Cuboid total surface area
- Triangle area

### How to Run

Compile:

    g++ shape_areas.cpp -o shape_areas

Run:

    ./shape_areas

## Assignment 2: Student Record System

File: student_record.cpp

This program uses a structure to store student information
and perform basic student record operations.

### Features

- Enter student name and ID.
- Enter course grade points.
- Calculate GPA.
- Display student results.
- Display registration status.

### How to Run

Compile:

    g++ student_record.cpp -o student_record

Run:

    ./student_record

## Technologies Used

- C++
- Structures (`struct`)
- Arrays
- Loops
- Conditional statements
- Basic arithmetic

## Learning Objectives

These programs demonstrate how to:

- Create and use structures.
- Store related information in a single record.
- Calculate areas using mathematical formulas.
- Store and process course grades.
- Calculate a student's GPA.
- Display student records and registration status.
